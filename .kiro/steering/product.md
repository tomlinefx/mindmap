# Product Overview

オンライン会議の発言から、AI がマインドマップ（「マップ」）を会議の最中に組み立て続ける Windows アプリ。上流の live-mindmap（macOS 専用、MIT）を Windows に移し、マップを他の端末のブラウザからも見られるようにしたもの。

使うのは、Windows PC で Zoom・Teams・Meet などの会議に出る日本語話者（主に保守者とそのチーム）。音を取ってマップを組み立てるのは Windows PC。マップは端末を選ばずブラウザで見る（Windows・macOS・Android・iOS など。セッションを動かしている PC 以外の端末は見るだけ）。

操作の入口は画面のボタンではなく CLI とスクリプト。AI エージェント（Claude Code）が CLI を叩く前提で作っている（上流 ADR 0003）。会議のたびの開始・終了は `/mindmap-start`・`/mindmap-stop` の 1 コマンド。

## Core Capabilities

1. **音声を PC の外に出さずに文字にする**: 会議アプリのプロセスの音だけを取り（相手）、マイクは別に取る（自分）。文字起こしは端末内 STT（日本語）。スピーカーから漏れた相手の声はエコーキャンセルで消し、消し残りには重複の印を付ける
2. **マップを差分で育てる**: 毎回作り直さず、Claude が今のマップに差分操作（追加・更新・統合・移動・削除・閉じる・何もしない）を当てる。マップは親子関係だけの木
3. **会議中の画面**: マップと字幕（まだマップに入っていない発言）を出す。カメラは今の議題に寄り、済んだ議題は畳む。長い会議でもマップは 1 枚で通す（上流 ADR 0005）
4. **閲覧の共有**: 同じ LAN（tailnet 越しも同じ口）の端末のブラウザに PIN 付き URL で見せる。OS は問わない。見る側はマップに何も返さない（ADR 0003）
5. **再現できる記録**: セッションごとに発言と差分操作の全記録を残し、終了時に map.md・map.json・map.html・map.drawnix を書き出す。過去の発言を流し直して差分更新をやり直せる（回帰の確かめに使う）

## Target Use Cases

- **会議のたび**: 会議に入る → `win-meeting-start`（サーバーと画面の起動・音を出している会議アプリの自動選択・セッション開始・他の端末用の URL・ブラウザ）→ 会議中はマップと字幕を見る（`M` で自分の声を休止）→ `win-meeting-stop` で書き出し
- **会議の後**: map.md の決定・TODO・未決の論点・アウトラインを読む / 共有する
- **開発時**: 記録した会議を再生して、差分更新の振る舞いの変化を確かめる

## Value Proposition

- 議事録を後で作るのではなく、会議の最中に構造（議題・論点・案・決定・TODO）が見える
- ノードはすべて根拠の発言（話者・時刻・原文）までたどれる
- 音声は残さず外に出さない。外に出るのは発言の文字だけ（差分更新のため Claude に送る。認証は利用者の `ANTHROPIC_API_KEY`）
- 会議アプリの音だけを取るので通知音などが混ざらず、自分と相手をトラックで分けられる
- 見る側の端末には何も入れない（OS を問わず、ブラウザで開くだけ）

## Domain Vocabulary

語彙の正本は `CONTEXT.md`。仕様・設計・コードはこの語彙で書く。特に取り違えやすいもの:

- **議題 / 論点**: 議題は話が集まる話題のまとまり（答えを出す対象ではない）。論点は答えを出すべき問い（未決 / 決定済み）
- **済み / 畳む**: 済みは AI が「閉じる」で決めるデータ。畳むは画面の見せ方で、人の操作を優先する
- **発言 / 途中結果**: 差分更新に使うのは確定した発言だけ。途中結果は字幕にだけ使う
- **トラック**: 自分（マイク）か相手（会議アプリ）
- **ヘルパー**: 音の取得と STT を行う Windows のプロセス（C#）。server が子プロセスとして起動する
- **セッション**: 1 つの会議を開始から終了まで追う作業。同時に 1 つだけ

## Scope Boundaries

- 上流から外したもの（ADR 0002）: publish・トンネルとメールの PIN・recorded・Apple 系・ChatGPT 連携・判定と振り分け・共有画面の OCR・話者分離・bench・e2e・map.png
- 作らないもの: 見る側のネイティブアプリ（Android・iOS など）、外出先から見るためのトンネル（Tailscale で足りる。固有の対応はコードに入れない）、共同編集、同時に複数のセッション
- 初版で作らないもの: クラウド STT（差し口だけ）、語彙補正、録音ファイル、自分の休止の自動判定。差分更新のモデルは Claude だけ
- 音を取りマップを組み立てる側は Windows 10 2004 以降だけ（Process Loopback の要件）。macOS / Linux で動かすことは対象外（見るだけならどの OS のブラウザでもよい）
- MIT、営利化しない（上流 ADR 0004 を引き継ぐ、ADR 0005）
