- [ ] 4. server で発言を 2 秒を超えて留めない
- [x] 4.1 (P) 指定の発言まで、話者待ちの保留を話者なしで出せるようにする
  - 指定の発言と、それより前に保留された発言を出す。話者がそろったものは話者付き、そろわないものは話者なし。すでに出た発言なら何も出さない
  - 保留に入った順を保つことと、二重に出ないことが単体テストで確かめられている
  - _Boundary: Speakers_
  - _Requirements: 3.1, 3.2_
- [x] 4.2 origin の壁時計をセッションに持ち、保留に入った発言に話し終えてから 2 秒の期限を張る
  - セッションで最初の origin の壁時計を、ライブのセッションの状態に持つ（7.1 のログもこれを使う）
  - 期限は origin の壁時計 + 発言の終わり + 2 秒。壁時計が無ければ保留に入った時刻 + 2 秒。期限の Fiber はセッションの Scope に属し、停止で止まる
  - 時間を進めるテストで、話し終えて 2 秒で保留が出る・その前に話者がそろえば二重に出ない・壁時計が無いときは保留に入った時刻から、が確かめられている
  - 偽の helper が壁時計付きの origin と話者分離の停止を出すと、相手の発言が待たずに差分更新へ渡ることが IT で確かめられている
  - _Depends: 2.1, 3.1_
  - _Requirements: 1.6, 2.4, 3.1, 3.2_

- [ ] 5. 差分更新の失敗で発言を落とさない
- [x] 5.1 呼び出しに時間切れを張り、失敗した回の発言を順番待ちの頭に戻す
  - 呼び出しが 20 秒を超えたら中断し、失敗と同じに扱う。失敗の回の発言は処理済みにせず頭に戻し、ログの diff の行に失敗と「戻した」印を残す
  - 再試行の間隔は 1 秒から倍々で 10 秒まで、成功で 1 秒に戻る。一時停止（利用上限）の扱いは変えない
  - 失敗・時間切れの後に発言が次の呼び出しに入り、間隔が延びることが単体テストで確かめられている
  - _Depends: 2.2_
  - _Requirements: 3.3, 3.4_
- [x] 5.2 同じ発言が 3 回続けて失敗したら 1 つだけで試し、それも失敗したら外す
  - 応答が返ってきたうえでの失敗だけを発言ごとに数え、時間切れ・つながらない失敗・一時停止は数えない
  - 頭の発言が 3 回に達したら次の呼び出しをその発言 1 つだけにし、それも失敗したら外す。diff の行には失敗と「1 つだけ」の印を残し、「戻した」印は付けない
  - 外した発言を「取り込めなかった」として、取り込み待ちの通知に渡せる形で持つ
  - 3 回目の後に 1 つだけの呼び出しになり、それも失敗すると外れて後ろの発言が進むこと、時間切れでは数えないことが単体テストで確かめられている
  - _Requirements: 3.5_
- [x] 5.3 restore で、戻した回の発言を取り込み待ちに戻す
  - 「戻した」印の diff の行は、反映した発言なしとして数える。印の無い失敗の行は今と同じく全部を反映済みとする
  - 失敗の回数は restore で 0 から数え直す
  - 「戻した」行を含むログを restore すると戻した発言が順番待ちにあり、「1 つだけ」の失敗の行の発言は反映済みであることがテストで確かめられている
  - _Depends: 2.2_
  - _Requirements: 3.3, 3.5_
