# スマホの録音の音声は、セッションのフォルダに残し、利用者が消すまで保つ

ADR 0001 は録音ファイルを初版では作らないとしたが、スマホの録音は、止めたあとで文字起こしをする（後からやり直す）ため、音声そのものが入力になる。そこで、サーバーはスマホから届いた音声をセッションのフォルダに残し、利用者がセッション単位で消すまで保つ。PC の会議の経路は変えない（音声を残さない）。

## Consequences

- 会議の生の音声がサーバーに残る。消す操作（セッション単位）を用意する。サーバーは利用者が管理する機器で、tailnet の中だけに開く（ADR 0007）
- 文字起こしのやり直しと、`再生` による回帰評価に音声を使える
- 断片が欠けた区間は取り込みの途切れとして残り、エクスポートに印を付ける
