# 話者分離はヘルパーが STT とは別のイベントで流し、サーバーが発言を話者で切る

`相手` のトラックの話者は、ヘルパーが FluidAudio の Sortformer（`fastV2_1`）で推定し、STT の `remark` / `partial` とは別の `speaker` イベント（トラック・開始 / 終了時刻・ラベル・仮か確定か）で流す。発言に話者を結び付けるのは、発言を締めているサーバーの中核で行う。`自分` のトラックは声で分けず、話者「自分」1 人として扱う（[#370](https://github.com/daiki-beppu/live-mindmap/issues/370)）。

1 つの発言の話者は 1 人までにする。`相手` の発言は、話者が替わったところで切る。そのために `remark` / `partial` に語ごとの区間を足す（SpeechAnalyzer は `.audioTimeRange` ですでに語の区間を返している）。発言は、その終わりまでの**確定**ラベルが揃ってから出し、出した後に話者を足したり変えたりしない。確定ラベルは音声から中央値 0.82 秒、95% で 1.04 秒遅れて届き（[#369](https://github.com/daiki-beppu/live-mindmap/issues/369)）、発言を締める 1 秒の待ちとほぼ重なるので、増える待ちは短い。3 秒待っても揃わなければ、話者なしで出す。

## Considered Options

- **ヘルパーが `remark` / `partial` に話者を載せる**: 途中結果から発言を作るのはサーバーなので、結局サーバーで合わせ直すことになる。STT を差し替えるたびに話者の載せ方にも触ることになり、「STT を差し替えても Web アプリ側のイベントの形は変えない」という ADR 0002 の約束が話者まで巻き込む
- **発言は切らず、話者の区間を複数持たせる**: 案の出した人を決めるときに、発言のどこが誰かを差分更新の AI か後段が読み解く必要がある。1 発言 1 話者なら、根拠の発言から出した人が機械的に決まる
- **発言をすぐ出して、話者は後から足す**: 「出した発言は書き換えない」に例外ができ、差分更新に渡した後の発言が変わる。待つ時間は 1 秒の締め切りとほぼ重なるので、例外を作るほどの得が無い
- **仮のラベルで発言を出す**: 仮から確定で行の多数決が変わるのは 0.6〜2.6% と少ないが、待つ時間がほとんど増えないのに、誤りを抱えたまま確定させる理由が無い。仮のラベルは字幕にだけ使う

## Consequences

- ラベル（相手 A / B …）は、サーバーがセッションの中で初めて話した順に振り、使い回さない。Sortformer の枠の番号をそのまま見せない
- 語の区間に確定ラベルが重なるときは、最も長く重なる話者にする。誰とも判定されない区間は同じ発言の前後の話者に寄せ、発言全体で誰もいなければ話者なしにする。0.5 秒未満の話者の区間は前後に寄せ、相づちで発言が細切れにならないようにする。重なりは合成会議の台本に無いので、実装後に回帰評価で確かめる
- `log.jsonl` には、発言に決まった話者と、`speaker` イベントの生の区間の両方を残す。対応付けの規則を変えたときに、録音からやり直さずに再生で測り直せる。話者を持たない古いログは、話者なしとして再生する
- Sortformer のモデルは、ヘルパーのセットアップ（AEC3 のビルドと同じ段）で取得し、セッション中には取りに行かない。音声は Mac の外に出ない
- 話者分離が使えないとき（モデルが無い・途中で落ちた）は、セッションを止めず話者なしで続ける。ヘルパーは `speaker-off` で知らせる（共有画面の `screen-off` と同じ扱い）
- Sortformer の枠は 4 つで、`相手` が 5 人以上だと声の近い枠に混ざる。この扱いは別に決める
- 追記（2026-10-13、[#987](https://github.com/daiki-beppu/live-mindmap/issues/987)）: `相手` の発言は、途中結果の文の終わりが落ち着いた時点でも締めるように変わる（地図 [#869](https://github.com/daiki-beppu/live-mindmap/issues/869)）。文の終わりは 1 秒待たずに締まるので、確定ラベルの待ち（中央値 0.82 秒）は 1 秒の締め切りと重ならず、その分がそのまま遅れになる。この ADR の決定は変えないが、話者分離を実装するときは、文の終わりで縮めた遅れの一部が戻ることを前提に測る
