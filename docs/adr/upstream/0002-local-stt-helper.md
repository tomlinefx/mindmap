# 音声取得と STT はローカルのヘルパーが SpeechAnalyzer で行い、Web アプリには文字起こしのイベントだけを渡す

会議音声の取得と文字起こしは、Swift で書いたローカルのヘルパー（常駐プロセス）が行う。相手の声は利用者が選んだ会議アプリのプロセスタップ、自分の声はマイクから取り、どちらも Apple の SpeechAnalyzer（端末内）に流す。Web アプリとの境界は localhost の WebSocket で、ヘルパーは途中結果と発言（トラック・開始 / 終了時刻・本文）を流すだけにする。

当初は Kanary の `transcribe` を STT の第一候補にしていたが、使わない。Kanary は内部で同じ SpeechAnalyzer を使っていて、60 分の会議 2 本で文字の一致率は 98.9% と精度は変わらない。一方で、チャンクに切ってファイルで渡すため、境界で語が抜ける。途中結果も取れない。Kanary.app の起動も前提になる。SpeechAnalyzer を直接ストリーミングで使えば、境界の処理は要らず、途中結果は 0.1 秒以内に届く。

スピーカーで聞くときは、相手の声がマイクにも漏れる。この漏れは、タップの音（スピーカーに出る音そのもの）を参照信号にした WebRTC AEC3 で、STT の前にマイクの音から消す。AEC3 は freedesktop の `webrtc-audio-processing` 2.1（BSD-3）を使う。取り切れなかった漏れへの保険として、文字列の重なりで重複を判定し、`自分` のトラックの発言に重複の印を付ける処理も残す。

AEC3 は Issue #110 で、マイクの音の 89% が漏れという録音で試した。漏れた会議の文言は文字にならず、話している利用者の声（−20 dB）はほぼ全文が残った。処理は 1 コアの 2% 弱で済んだ。speexdsp も試したが、そのときの解析は参照をエコーより 10 ms 遅らせて渡していた（2026-10-06 に判明）ので、効くかどうかは分かっていない。参照とマイクの時刻を揃えないと消えないので、両方の hostTime で揃える。同じ分野の Kanary も、プロセスタップの音を参照にした AEC3 を、C++ の薄いシムに包んで同梱している。

AEC3 は C++ なので、依存は C++ の薄いシム 1 枚に閉じ込める。ライブラリは、版を固定したソースをスクリプトで静的ライブラリにビルドして使い、バイナリは git に入れない。

Apple の音声処理（Voice Processing）は使わない。エコーキャンセルの効き目は十分で、会議アプリの音も消せた。それでも見送ったのは、他のアプリへの副作用が公開 API では避けられないためだ（Issue #110 で実測した）。

- 自分のプロセスで有効にすると、別プロセスのマイク入力が約 25 dB 絞られる。会議アプリが自分で音声処理を使っていなければ、利用者の声が相手にほとんど届かなくなる
- 他のアプリの音を下げる（ダッキング）。公開 API で最も弱い設定（`.min`）でも −8 dB 下がる。止める旧プロパティは macOS では使えない。止めるには非公開 API（`AudioDeviceDuck`）しかないが、非公開 API は使わない

当初の理由にした「同じプロセスで有効にするとタップが止まる」は、こちらの使い方の問題だった。タップを載せる集約デバイスに出力デバイスをサブデバイスとして入れていたので、音声処理が出力デバイスに足すストリームが入ってきて、入力の形式が変わっていた。タップだけで集約デバイスを作れば、同じプロセスでも取り続けられる。

## Consequences

- ヘルパーは macOS 26 以降（SpeechAnalyzer）と macOS 14.4 以降（プロセスタップ）を前提にする。Windows や Linux では動かない
- マイクとシステム音声の権限は、ヘルパーを起動したアプリ（ターミナルなど）に付く
- クラウドのストリーミング STT に差し替えるときは、ヘルパーの中で STT を入れ替える。Web アプリ側のイベントの形は変えない
- 自分と相手が同時に話したときに、重複判定が自分の発言まで捨てないかは、実装時に回帰評価で確かめる
- ヘルパーのビルドとテストの前に、AEC3 の静的ライブラリをビルドするスクリプトを 1 回走らせる。手元にも CI にも、meson と ninja（`uvx` で一時的に使える）が要る
- Voice Processing を見直すなら、タップは出力デバイスを入れない集約デバイスに載せ、会議アプリ側のマイクへの影響を実際の会議で確かめる
