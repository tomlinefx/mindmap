# 共有画面は、選んだ会議アプリのウィンドウからピッカーを使わずに取り込む

共有画面は、ScreenCaptureKit で、選んだ会議アプリの bundle id からウィンドウを特定して直接取り込む。システムのウィンドウピッカーは使わない。会議アプリを選べば、音声と一緒に画面も付いてくる。このため、利用者に新しい手順は増えない。代わりに「画面収録」の許可が 1 つ増え、macOS 15 以降は OS が月に 1 回、ピッカーを回避していることを確認する。許可が無いか断られたときは、セッションを止めず、共有画面なしで音声だけで続ける（[#185](https://github.com/daiki-beppu/live-mindmap/issues/185)）。

## Considered Options

- **ピッカーでセッションごとにウィンドウを選ぶ**: 毎月の確認は出ない。ただし、ピッカーは候補を会議アプリのウィンドウだけに絞れず（除外の指定しかない）、毎回選ぶ手順と選び間違いの余地が増える
- **毎月の確認を避ける entitlement を申請する**: Apple の承認が要り、通る見込みが低い（[#180](https://github.com/daiki-beppu/live-mindmap/issues/180)）
