# マップのノード同士の関係は親子だけにする

マップは木とし、「この案はあの課題への対策」「この決定はこの案を採用した」のような、木をまたぐリンクは持たない。リンクを持つと、差分操作の種類が増えて LLM の出力が不安定になり、描画ライブラリの候補も限られる（markmap はリンクを描けない）。MVP ではその複雑さに見合う価値がまだ確かめられていないので、親子だけにした。

## Consequences

- 種別をまたぐ関係は、親子関係で表す（決定は論点の子に、採用した案の内容は決定の本文に書く）
- 後からリンクを加える場合、差分操作・操作ログ・描画のすべてに手を入れることになる
